# Finanças Pessoais — app instalável

Pasta pronta para publicar no GitHub Pages (ou Netlify). Faz a app do Apps Script abrir
como uma app a sério no telemóvel: ícone próprio, ecrã inteiro, sem barra do Chrome,
sem o aviso "created by a Google Apps Script user", e sempre na mesma janela.

## 2. Publicar (GitHub Pages, grátis)
1. github.com → New repository → nome `financas-pessoais` → Public → Create.
2. Add file → Upload files → arrasta TODOS os ficheiros desta pasta → Commit.
3. Settings → Pages → Branch: main, folder: / (root) → Save.
4. Passado 1–2 min o site fica em `https://<utilizador>.github.io/financas-pessoais/`.

## 3. Instalar no telemóvel
- **Android (Chrome):** abre o link → menu ⋮ → "Instalar aplicação" (ou "Adicionar ao ecrã principal").
- **iPhone (Safari):** abre o link → Partilhar → "Adicionar ao ecrã principal".

A partir daí abre pelo ícone. Na primeira vez pode pedir para iniciares sessão na Google:
toca em "Iniciar sessão", entra, e volta à app.

## Atualizar a app
Nada a fazer: a casca aponta sempre para o link do Apps Script, por isso quando fazes
"Nova versão" no Apps Script a app no telemóvel fica logo atualizada.
