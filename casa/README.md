# Finanças Casa — app instalável

A app corre aqui (GitHub Pages) e entra com a conta Google; os dados vivem na folha Google Sheets,
através do Apps Script (`doPost`), que só aceita contas autorizadas.

Instalar: Android (Chrome) → ⋮ → "Instalar aplicação"; iPhone (Safari) → Partilhar → "Adicionar ao ecrã principal".
