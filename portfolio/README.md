# Portfólio — app instalável

Casca (PWA) que abre a app do Apps Script "Portfólio" como uma app a sério no telemóvel.
Enquanto o `index.html` tiver `__URL_PORTFOLIO__`, a app ainda não está ligada: substituir
pelo link `/exec` da implementação do Apps Script (Implementar → Nova implementação → Aplicação Web).

Instalar: Android (Chrome) → ⋮ → "Instalar aplicação"; iPhone (Safari) → Partilhar → "Adicionar ao ecrã principal".
